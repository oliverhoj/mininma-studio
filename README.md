# minima studio

Lokal, responsiv hjemmeside inspireret af thenew-studio.com.

Åbn denne mappe i VS Code, og åbn index.html med Live Server, eller kør:

    python3 -m http.server 8000

Åbn derefter http://localhost:8000.

Skrifttype: Helvetica Neue med Helvetica og Arial som reserve, hvis Helvetica Neue ikke er installeret. Alle brandnavne er minima studio med små bogstaver.

Menu, søgning, informationspaneler og mobilvisning er implementeret. Betaling, kundekonti, produktkatalog og nyhedsbrevsudsendelse kræver tilslutning til en rigtig webshop. Tilmeldingsformularen gemmer kun interessen lokalt i browseren.

Kampagnebilledet er en lokal kopi af referencesidens offentlige kampagnebillede og bør udskiftes med virksomhedens eget billede før offentlig lancering.
